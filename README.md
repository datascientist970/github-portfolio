## Overview

This repository contains the source of my personal portfolio website (`index.html`). It is intentionally built with vanilla web technologies — no framework, no build step — so it loads fast and can be hosted anywhere static files are served (e.g., GitHub Pages).

## Getting Started

No build or installation is needed — just clone and open:

```bash
git clone https://github.com/datascientist970/github-portfolio.git
cd github-portfolio
```

Open `index.html` in a browser, or serve it locally:

```bash
python -m http.server 8000
# then visit http://127.0.0.1:8000
```

## Usage

Use it as a template Reference for a clean single-page portfolio: edit the text sections in `index.html`, replace `images/profile.png` with your own photo, and adjust colors/layout in `css/style.css`.
